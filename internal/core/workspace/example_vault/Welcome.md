# Explore the example Vault

Open [[Project/Field Notes]] in Split View to edit Markdown beside its preview. Open the Vault graph to follow the links between the examples.

- [[Slide Deck]] can be played from the editor’s Slideshow menu.
- [[Review Cards]] has two questions for Flash Cards.
- [[Charts]] renders a local CSV file. Edit a reading to see how the data changes.

Open GLOW and type `/` to browse commands for the current note and workspace. Type `demo` for a guided tour using [[System Architecture]] and the crew notes.
